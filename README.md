# Arthur Sales

## About me

Backend developer graduated in Computer Science, currently building an ATS platform in Java/Spring Boot. Outside of work, I spend a lot of time customizing my Linux desktop — building Omarchy themes, tuning Hyprland, and occasionally going down compiler-design rabbit holes for fun.

### What I work on

- **Backend systems** — Java, Spring Boot, Spring Data JPA, Spring Security (JWT/OAuth), REST APIs
- **Omarchy themes** — full desktop color systems with practical config coverage (Hyprland, Waybar/Quickshell, terminal, Neovim, GTK)
- **Language tooling** — small compilers/transpilers, built to actually understand how lexing, parsing and codegen work under the hood
- **Linux desktop workflows** — Arch, Hyprland, dotfiles, keyboard firmware (QMK/Vial)

### Core stack

`Java` · `Spring Boot` · `Docker` · `PostgreSQL` · `C++` · `Bash` · `Lua` · `Hyprland` / `Omarchy`

## Compatibility

My Omarchy themes are built and tested around:

- Arch Linux + Hyprland (Omarchy 3.x and Quattro/Quickshell)
- `colors.toml`-driven theming, including the newer ANSI-16 schema used by Omarchy Quattro

If your setup differs, open an issue with your environment details and I'll help confirm compatibility.

## Issue and contribution guide

Use the target repository's Issues page and include:

- Environment details (Omarchy version/channel, Hyprland version, GPU)
- Exact steps to reproduce
- Expected result vs. actual result
- Relevant logs/screenshots when applicable
